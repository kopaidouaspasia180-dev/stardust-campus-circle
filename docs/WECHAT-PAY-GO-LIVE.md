# 微信支付上线配置

代码已覆盖校园外卖、校园商店和兼职付费发布的 JSAPI 下单、支付回调、支付重试、超时关闭、取消退款、退款回调与失败重试。测试商品永远不会发起支付。

## 上线前必须由商户平台提供

- 与小程序 AppID 绑定的微信支付商户号
- 商户 API 证书序列号与商户私钥文件
- 32 字节 API v3 密钥
- 微信支付公钥文件与公钥 ID（推荐），或仍有效的平台证书与序列号
- 可公网访问的 HTTPS 支付回调与退款回调地址
- 商户平台中已配置的结算账户、退款权限和操作员权限

这些值只写入服务器的 `.env.production` 和受限密钥目录，不得写入小程序、H5、Git 仓库或聊天记录。

## 服务端开关

完成配置后将 `CHECKOUT_MODE` 从 `offline` 改为 `wechat`。服务在缺少任一必要参数、AppID 不一致或验签材料不完整时会拒绝启动，避免出现订单收费状态不一致。

上线前执行：

```bash
npm --prefix server run preflight:production -- --env /path/to/.env.production --check-files
```

## 必测闭环

1. 使用真实微信账号以 0.01 元内部测试商品下单。
2. 确认支付成功回调验签通过，订单只在回调后进入已支付/待接单。
3. 重复回调不得重复记账或重复通知。
4. 用户取消和运营拒绝均进入退款队列，退款回调后状态变为已退款。
5. 金额、商户号、AppID、订单号或退款号不匹配时必须拒绝。
6. 对账确认微信商户订单、项目订单和结算金额一致后，才能开放正式商品。

资金结算到微信支付商户平台配置的结算账户，代码不能把款项改流向个人银行卡。
