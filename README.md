# Stardust 校园生态小程序

这是独立于现有单校 H5 项目的多高校校园生态微信小程序工程。

## 当前能力

- 一个小程序内切换高校和校区。
- 首页、校园圈、校园服务、校园 AI、我的五个原生页面。
- 新生内容降级为普通校园工具入口。
- 唐山学院作为当前已开通的高校租户；其余高校保持筹备状态，不能切换到空数据租户。
- 其他高校可由平台后台开通，不再复制前端工程。
- API 契约和 PostgreSQL 多租户表结构已建立。
- 高校与校区双重数据隔离；二手、学生兼职、失物招领支持校内私聊与举报。
- 校园服务在线支付本期保持关闭；兼职岗位由校区运营核验后统一录入，同学可投递与校内沟通。
- 校园圈支持先审后发、我的发布、状态反馈、撤回、点赞、评论、帖子/评论举报与后台处置。
- 校园榜单支持学生投稿、人工审核、点赞、举报、投稿撤回和运营下架。
- H5 构建包含统一运营后台 `admin/`，可审核内容、处理兼职发布、管理举报、角色、校区联系方式和审计日志。

## 本地构建

```powershell
npm.cmd install
npm.cmd run build:weapp
```

构建完成后，使用微信开发者工具导入本目录；`project.config.json` 的 `miniprogramRoot` 已指向 `dist/`。

运营后台随 H5 一起构建，部署后的入口为 `/campus-circle/admin/`。首次连接需使用服务端配置的 `ADMIN_BOOTSTRAP_TOKEN`，正式运营后应为工作人员分配最小权限角色，并定期轮换引导令牌。

## 上架前必须配置

1. 将 `project.config.json` 中的 `touristappid` 换成企业主体小程序 AppID。
2. 配置备案完成的 API、上传和下载域名。
3. 完成隐私协议、用户信息用途说明和内容安全机制。
4. 接入微信登录及服务端会话。
5. 开放社区前完成文本、图片审核、举报、封禁和审计。
6. 当前版本不要开启支付；未来开放前需完成商户号、订单、退款和交易类目核验。

AppSecret、商户 API 密钥和证书不得提交到本项目或发送到聊天中。
