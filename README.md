# Stardust 校园生态小程序

这是独立于现有单校 H5 项目的多高校校园生态微信小程序工程。

## 当前能力

- 一个小程序内切换高校和校区。
- 首页、校园圈、校园服务、校园 AI、我的五个原生页面。
- 新生内容降级为普通校园工具入口。
- 唐山学院作为首个激活租户。
- 其他高校可由平台后台开通，不再复制前端工程。
- API 契约和 PostgreSQL 多租户表结构已建立。

## 本地构建

```powershell
npm.cmd install
npm.cmd run build:weapp
```

构建完成后，使用微信开发者工具导入本目录；`project.config.json` 的 `miniprogramRoot` 已指向 `dist/`。

## 上架前必须配置

1. 将 `project.config.json` 中的 `touristappid` 换成企业主体小程序 AppID。
2. 配置备案完成的 API、上传和下载域名。
3. 完成隐私协议、用户信息用途说明和内容安全机制。
4. 接入微信登录及服务端会话。
5. 开放社区前完成文本、图片审核、举报、封禁和审计。
6. 开放支付前完成商户号、订单、退款和交易类目核验。

AppSecret、商户 API 密钥和证书不得提交到本项目或发送到聊天中。
